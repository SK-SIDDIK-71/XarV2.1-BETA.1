## 🚀 Getting Started

### 1. Create Your Telegram Bot

Open Telegram and search for **BotFather**.

1. Start a chat with BotFather.
2. Use `/newbot`.
3. Follow the instructions.
4. Copy your Telegram bot token.

> ⚠️ **Never publish your real bot token in a public repository.**

---

### 2. Clone the Repository

```bash
git clone https://github.com/SK-SIDDIK-71/XarV2.1-BETA.1.git
cd XarV2.1-BETA.1
```

---

### 3. Install Dependencies

XarV2.1 uses **Bun** as its runtime.

```bash
bun install
```

---

### 4. Configuration

Configure the bot using the project's configuration files.

Main configuration:

```text
config.json
```

Before starting the bot, make sure your required bot credentials are correctly configured.

> 🔐 Keep your bot token and other private credentials secure.

---

### 5. Start the Bot

Run the main TypeScript entry point with Bun:

```bash
bun run index.ts
```

### ❌ Do Not Use

```bash
npm start
```

The project does not provide an `npm start` script.

Also avoid:

```bash
node index
```

Use **Bun** to run the project.

---
